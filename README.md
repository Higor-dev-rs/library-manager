# Library Manager

Sistema de gerenciamento de biblioteca desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos (POO) e acompanhar a minha evolução dos estudos.

## Objetivo

Este projeto faz parte da minha jornada de aprendizado em Java. A proposta é evoluí-lo gradualmente, aplicando novos conceitos à medida que forem sendo estudados, desde os fundamentos da linguagem até o desenvolvimento de uma API REST com Spring Boot.

## Tecnologias

- Java 21
- Maven
- Git
- GitHub
